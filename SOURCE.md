# Website Source

This local draft adapts the HTML structure, stylesheet, and paired-video
controller from https://github.com/visual-force/visual-force.github.io
at commit `76130a7bffa8ddd9b708d01e54187a4331ed3566`.

- `static/css/index.css` is the upstream stylesheet, unchanged.
- `static/css/dsp.css` contains local layout overrides.
- `index.html` adapts the upstream section structure to DSP content.
- `static/js/index.js` adapts task selection and paired playback to optional DSP media.
- VisualForce authors, results, manuscripts, videos, and interactive force data
  are not included as DSP research content.

No explicit license file was present in the upstream tree when inspected.
This note is attribution, not a license grant. Confirm permission to reuse the
website source before public release. No deployment has been configured.
